# Clinic Companion

A patient-facing web app for outpatient clinic visits. Shows patients where they are in the queue, explains their results in plain language, and lays out what the visit costs.

Most clinic software is built for the people running the clinic. Patients sit in a waiting room with no idea how long they'll be there, then leave holding a report they can't read and a bill they didn't expect. I built this as a prototype of the other side of that — the same visit, rendered for the person going through it.

**[Live demo →](https://harrisfarhan83-beep.github.io/clinic-companion)**

## Features

- **Queue position** — where you are in line and a rough wait estimate
- **Plain-language results** — lab and test findings translated out of clinical shorthand
- **Visit costs** — what's being charged and for what, before you reach the counter

## Data

Runs entirely on synthetic data. No real patient information is used anywhere in this project.
